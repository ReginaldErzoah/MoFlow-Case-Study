# MoFlow - Business Analysis Case Study

> An end-to-end Business Analysis case study for a mobile-first recurring bill payment platform, demonstrating business analysis, requirements engineering, user research, UX design, process modelling, and Agile delivery.

---

## Project Overview

MoFlow is a conceptual mobile-first platform that enables individuals and small businesses to automate recurring bill payments using Mobile Money. The platform helps users schedule, manage, and monitor recurring payments for utilities, rent, school fees, insurance, subscriptions, and other routine financial obligations.

This repository showcases the complete Business Analysis lifecycle, from problem identification and stakeholder analysis to requirements documentation, UX design, process modelling, and Agile project delivery.

---

## Business Problem

Many Mobile Money users manually initiate recurring payments each month, leading to:

- Missed payment deadlines
- Late payment penalties
- Service interruptions
- Poor visibility into upcoming financial obligations
- Time-consuming manual payment processes

MoFlow addresses these challenges by providing a central platform for scheduling recurring payments, receiving reminders, tracking payment history, and managing recurring financial commitments.

---

## Proposed Solution

MoFlow enables users to:

- Register and securely authenticate
- Link Mobile Money accounts
- Schedule recurring bill payments
- Automate payment execution
- Receive payment reminders and confirmations
- Monitor upcoming payments
- View payment history
- Manage recurring payment schedules
- Access a dashboard with key payment insights
